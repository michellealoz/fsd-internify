# FSD Mini Project: Internify

## Project Overview

The Internify is a platform designed to help students track their internship applications and progress. Students can apply for internships, monitor the stages of their applications, and receive feedback from mentors. This project is aimed at helping students stay organized and manage their internship search effectively.

## Features:
- **User Authentication**: Students can register and log in to manage their internship applications.
- **Application Tracking**: Track internship applications with stages, feedback, and status updates.
- **Admin Dashboard**: Admin can manage internship postings, applications, and track student progress.
- **Real-time Updates**: Students and Admins can see real-time updates on the application statuses.

## Technologies Used

- **Frontend**:
  - React.js
  - Tailwind CSS
  - JavaScript 

- **Backend**:
  - Node.js
  - Express.js
  - MongoDB (using MongoDB Atlas)
